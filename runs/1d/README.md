# 1D runs

Place reproducible chain calculations here. The first tracked case should be
a small-system reproduction target with a dense reference feasible at the
same `L`.

For each case, compare at least the final site density, nearest-neighbour bond
order, particle number, Hartree–Fock energy components, and SCF stationarity.
If SP2 and Palser–Manolopoulos are both applicable, use their agreement as a
cross-check, not as a substitute for a dense small-system reference.
